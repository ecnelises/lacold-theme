# Lacold for CotEditor

Double-click a `.cottheme` file to import it, or use **Settings > Appearance >
Theme > Action (…) > Import**. Select the Lacold Light and Dark variants you
want CotEditor to use for each system appearance.

For a manual installation, copy the files into CotEditor's sandboxed user
Themes directory, then relaunch CotEditor:

```sh
mkdir -p ~/Library/Containers/com.coteditor.CotEditor/Data/Library/Application\ Support/CotEditor/Themes
cp *.cottheme ~/Library/Containers/com.coteditor.CotEditor/Data/Library/Application\ Support/CotEditor/Themes/
```
